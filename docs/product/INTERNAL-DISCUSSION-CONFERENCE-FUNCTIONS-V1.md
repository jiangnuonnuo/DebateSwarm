# AI 内部讨论大会 - 产品功能方案 V1（第一步，不落地）

## 0. 当前阶段边界
- 目标：先把完整产品功能定义清楚。
- 范围：仅做产品方案，不做后端/前端编码实现。
- 角色载体：第一阶段统一用 `CLIENT` 扮演角色，后续再增强到 `AGENT`。

## 1. 目标用户与核心价值
- 目标用户：创建会议并驱动多角色 AI 讨论的产品/研发负责人。
- 核心价值：
  - 可配置的多角色讨论流程
  - 可控的经理评审机制
  - 可复盘的结构化结论与行动项

## 2. 完整功能清单（产品层）

### 2.1 会议模板中心
- 新建模板 / 编辑模板 / 复制模板 / 启停模板
- 模板包含：
  - 默认角色集
  - 默认顺序与轮次
  - 默认角色提示词模板
  - 默认输出格式（claim/evidence/risk/action）

### 2.2 会议创建（实例化）
- 基础信息：
  - 会议名称
  - 议题
  - 目标
  - 背景上下文
- 约束信息（用户自定义）：
  - 时间/资源/技术边界
  - 风险偏好
  - 不可触碰项
- 产出要求：
  - 期望结论格式
  - 行动项字段要求
- 创建方式：
  - 从空白创建
  - 从模板创建

### 2.3 角色配置
- 角色库（初始）：产品、后端、前端、测试、架构、经理
- 角色绑定：
  - 每个角色绑定一个 `clientId`
  - 支持随时替换绑定（不可写死）
- 提示词配置：
  - 系统默认模板
  - 会议级覆盖模板
  - 单次临时补充指令
- 角色启停：可在会前禁用某角色

### 2.4 流程编排（拖拽）
- 发言顺序拖拽编排
- 轮次配置：
  - 总轮次
  - 每轮参与角色
- 经理节点：
  - 每轮末自动进入经理评审
- 例外控制：
  - 跳过角色
  - 指定角色重答

### 2.5 会中执行页
- 实时展示：
  - 当前轮次、当前发言角色、进度
- 结构化发言卡片（强约束）：
  - claim
  - evidence
  - risk
  - action
- 经理动作：
  - 通过
  - 退回补充
  - 否决
  - 指定某角色追答
  - 开启下一轮
  - 提前结束会议
- 人工介入：
  - 用户可插入额外指令

### 2.6 会议结果页
- 最终结论摘要
- 争议保留（少数意见）
- 行动项清单：
  - 任务
  - 责任角色
  - 优先级
  - 截止建议
- 导出：
  - 文本
  - Markdown

### 2.7 历史与复盘
- 会议列表（进行中/已完成）
- 会议详情回放（按轮次与角色）
- 模板回收复用（从历史会议回生模板）

### 2.8 权限与治理（产品规则）
- 创建者可配置会议与流程
- 经理拥有评审闭环权限
- 所有配置变更需要有审计记录入口

## 3. MVP 范围（第一落地批次）
- 会议创建（议题/目标/约束/产出要求）
- 角色绑定可替换 + 默认提示词模板
- 拖拽顺序编排
- 会中结构化发言
- 经理评审动作
- 会议结论与行动项输出

## 4. 后续增强（非第一批）
- 自动质量评分与追问
- 并行角色发言
- 更强报告结构（风险矩阵、多方案对比）
- 引入 `AGENT` 作为增强执行角色
