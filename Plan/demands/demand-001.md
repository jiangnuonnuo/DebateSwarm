# Demand: demand-001

## Original Demand
- 从 0 设计「小红书智能发布」独立功能，挂载在 Work 对话界面内可直接试用。
- 采用 DDD/六边形架构方法进行分层设计，并与项目经理逐步确认需求后再定稿。
- 功能支持多 Agent 工作流，复用现有 Agent 基建能力，但不复用不匹配的旧业务模型。

## Product Intent
- 提供两种发布模式：
  - A 模式：人机协作，文案后审核 + 发布前审核。
  - B 模式：全自动执行，仅输出最终成果。
- 支持小红书多账号绑定与任务级账号选择。
- 支持知识库增强（个人库优先，补充共享库）与发布结果可追踪。
